Geometry epidemiology

Five small studies that borrow epidemiology’s methods: measurement agreement, growth charts, equity, misclassification, and secular trends, applied to gravel bike geometry.

Epidemiologists spend a lot of time asking whether two measurements agree, where someone sits against a reference population, whether a group is being served as well as everyone else, whether a label matches what’s really going on, and how things have changed over time. The same questions work surprisingly well on bike geometry.

1. Do the charts agree with themselves? 2. Growth charts for bikes 3. Do smaller riders get the same bike? 4. Does the marketing match the data? 5. Are gravel bikes getting longer and slacker?

// Nudge labels so they don't overlap: place them one by one, and move a label
// down (in 13 px steps) while it overlaps a label already placed. Needs the
// plot's pixel size and fixed domains to convert data to pixels.
nudge = (data, {x, y, text, xDomain, yDomain, width, height, marginLeft = 50, marginRight = 20, marginTop = 20, marginBottom = 30, dx = 8}) => {
  const px = v => marginLeft + (v - xDomain[0]) / (xDomain[1] - xDomain[0]) * (width - marginLeft - marginRight);
  const py = v => marginTop + (yDomain[1] - v) / (yDomain[1] - yDomain[0]) * (height - marginTop - marginBottom);
  const placed = [];
  return [...data].sort((a, b) => py(a[y]) - py(b[y])).map(d => {
    const w = String(d[text]).length * 6.2, x0 = px(d[x]) + dx;
    let top = py(d[y]) - 7, shift = 0;
    while (placed.some(p => x0 < p.x1 && x0 + w > p.x0 && top + shift < p.y1 && top + shift + 13 > p.y0) && shift < 120) shift += 13;
    placed.push({x0, x1: x0 + w, y0: top + shift, y1: top + shift + 13});
    const perPx = (yDomain[1] - yDomain[0]) / (height - marginTop - marginBottom);
    return {...d, _dy: shift, _yl: d[y] - shift * perPx};
  });
}

1. Do the charts agree with themselves?

Method: Bland–Altman agreement, the standard way to compare two ways of measuring the same thing.

A geometry chart has more numbers than it strictly needs: trail, wheelbase, top tube, and fork offset can each be recalculated from the others. If the chart is internally consistent, the published and recalculated values should agree. Each dot below is one frame size. The solid line is the average difference (the bias), and the dashed lines are the 95% limits of agreement, inside which about 95% of differences fall.

agreement = FileAttachment("data/epi_agreement.csv").csv({typed: true})
agreementSummary = FileAttachment("data/epi_agreement_summary.csv").csv({typed: true})
measureOrder = ["Wheelbase", "Fork offset", "Trail", "Top tube"]
{
  const panels = measureOrder.map(m => {
    const d = agreement.filter(r => r.measure === m);
    const s = agreementSummary.find(r => r.measure === m);
    const lim = Math.max(8, ...d.map(r => Math.abs(r.diff))) * 1.1;
    const plot = Plot.plot({
      width: 480, height: 260, marginLeft: 40, marginBottom: 36, style: plotStyle,
      x: {label: `Average of the two (mm) →`, nice: true, grid: true},
      y: {label: "↑ Calculated − published (mm)", domain: [-lim, lim], grid: true},
      marks: [
        Plot.ruleY([0], {stroke: "#c9d6e0"}),
        Plot.ruleY([s.bias], {stroke: "#0b2233", strokeWidth: 1.5}),
        Plot.ruleY([s.loa_low, s.loa_high], {stroke: "#0b2233", strokeDasharray: "4,3"}),
        Plot.dot(d, {x: "mean", y: "diff", r: 3.5, fill: "#7a5c43", fillOpacity: 0.7, stroke: "#fff", strokeWidth: 0.8,
          channels: {Bike: d => `${d.brand} ${d.model}`, Size: "size_label", Published: "published", Calculated: "calculated"},
          tip: true})
      ]
    });
    return html`<figure class="ba-panel"><figcaption><strong>${m}</strong> <span>${s.n_sizes} sizes, ${s.n_bikes} bikes · bias ${Math.abs(s.bias) < 0.05 ? "0.0" : (s.bias > 0 ? "+" : "") + s.bias.toFixed(1)} mm · limits ${s.loa_low.toFixed(1)} to +${s.loa_high.toFixed(1)} mm</span></figcaption>${plot}</figure>`;
  });
  return html`<div class="ba-grid">${panels}</div>`;
}

What it shows. The charts mostly agree with themselves, so the typed-in numbers can be trusted. The exceptions come from brands measuring things slightly differently, not from typing mistakes.

  • Wheelbase and fork offset agree almost perfectly, within about ±1.3 mm. The charts are internally consistent, and the method this site uses to estimate missing fork offsets is reliable.
  • Trail agrees within about ±4 mm. Most of the spread is the reference tyre: each brand assumes a different tyre when it calculates trail, and few say which.
  • Orbea is the outlier. Its published trail sits about 5 mm below the recalculated value at every size, which fits its chart assuming a smaller tyre than the 700 × 45 mm used here.
  • Top tube has the widest limits (about ±7 mm). A few brands measure top tube to a different point. The OPEN WI.DE. even publishes two top tube figures.

2. Growth charts for bikes

Method: reference centiles from quantile regression, the technique behind paediatric growth charts.

A growth chart shows the range of heights children usually have at each age. Here, the shaded bands show the range of stack that bikes usually have at each reach, across all 135 production sizes. A size above the 95th centile is unusually tall for its length. Below the 5th, it’s unusually low.

Bands: 5th to 95th centile (light) and 25th to 75th (darker), with the median line. The z-score is the distance from the median line in robust standard deviations (interquartile range ÷ 1.349), so ±1.645 marks the 5th and 95th centiles.

What it shows. Almost every size (129 of 135) falls inside the 5th to 95th centile band. The sizes outside it make sense:

  • The tallest Salsa Cutthroat sizes, a drop-bar mountain bike built for long-distance touring, with a tall suspension-corrected fork.
  • The largest Cannondale Topstone and Specialized Diverge, which both have suspension in or under the front end.
  • The smallest Factor ELARA, below the 5th centile: an aero race bike that keeps its small size low.

3. Do smaller riders get the same bike?

Method: an equity comparison, using the rider model from the Rider page.

Bikes are usually designed around a middle size and then scaled. Riders at the ends of the height range, often women and shorter men at the small end, may get a different bike: slacker or steeper angles to fit the wheels in, more toe overlap, or no size that fits at all.

4. Does the marketing match the data?

Method: unsupervised clustering against an assigned label, with agreement measured by Cohen’s kappa, much as a diagnostic label is checked against an independent classification.

This site sorts bikes into race, all-round, and adventure, based on how each manufacturer describes them. Here, the 24 bikes are grouped again using geometry alone, then the two groupings are compared. Each bike is described by its middle size on six measures that don’t depend on size: stack-to-reach ratio, head angle, trail, chainstay length, BB drop, and tyre clearance. They are clustered into three groups (Ward’s method on standardised values).

5. Are gravel bikes getting longer and slacker?

Method: a secular trend comparison, like tracking average height across birth cohorts, with every generation standardised to the same rider.

Mountain bikes spent the 2010s getting longer, lower, and slacker. Has the same thing happened to gravel bikes? Seven of the bikes on this site have older generations whose geometry charts survive in the Internet Archive‘s copies of the manufacturers’ own pages. That gives 9 older charts to set against today’s.

Comparing size “M” with size “M” doesn’t work, because brands move their sizes around between generations. So each generation is standardised to the same rider: every measure is read off at the size whose stack (the height of the front end) is 580 mm, which is about a medium. Wheelbase and trail are recalculated from the frame numbers the same way for every chart, so a brand’s rounding or tyre assumption doesn’t count as a change.

Light dot: oldest chart found. Dark dot: today’s bike. Brown dot: a generation in between. Bikes are sorted by how much they changed. For head angle, a move left means slacker steering.

{
  const ch = lineages.map(l => {
    const g = overTime.filter(d => d.lineage === l).sort((a, b) => a.chart_year - b.chart_year);
    const f = g[0], c = g.at(-1);
    return {l, hta: c.head_tube_angle - f.head_tube_angle, wb: c.wheelbase - f.wheelbase, reach: c.reach - f.reach, drop: c.bb_drop - f.bb_drop, cs: c.chainstay - f.chainstay};
  });
  const n = ch.length;
  const count = (k, test) => ch.filter(d => test(d[k])).length;
  const med = k => median(ch.map(d => d[k]));
  const norco = ch.find(d => d.l === "Norco Search");
  return md`**What it shows.** Gravel bikes have got slacker, lower, and longer at the back, but not simply longer in reach.

- **Slacker steering.** ${count("hta", v => v < -0.25)} of ${n} bikes now have a slacker head angle than their oldest chart (median change ${med("hta") < 0 ? "−" : "+"}${Math.abs(med("hta")).toFixed(1)}°). The Norco changed most, by ${Math.abs(norco.hta).toFixed(2)}°.
- **Lower bottom brackets.** ${count("drop", v => v > 2)} of ${n} have more BB drop, which sits the rider lower between the wheels, and ${count("drop", v => v < -2) === 0 ? "none has less" : `${count("drop", v => v < -2)} have less`}.
- **Longer at the back.** ${count("cs", v => v > 2)} of ${n} have longer chainstays (more tyre room), and ${count("cs", v => v < -2) === 0 ? "none is shorter" : `${count("cs", v => v < -2)} are shorter`}.
- **Wheelbase mostly grew.** ${count("wb", v => v > 5)} of ${n} are more than 5 mm longer between the axles (median ${med("wb") > 0 ? "+" : ""}${med("wb").toFixed(0)} mm). The Norco grew most, by ${norco.wb.toFixed(0)} mm.
- **Reach went both ways.** ${count("reach", v => v > 5)} bikes got more than 5 mm longer and ${count("reach", v => v < -5)} got more than 5 mm shorter, for the same handlebar height. Where reach shrank, the newer bike puts the rider more upright rather than more stretched out.

Unlike mountain bikes, there's no single "longer" trend. The consistent change is lower and slacker, with longer chainstays for wider tyres.`;
}

How these were done

The analyses for studies 1, 2, 4, and 5 are in R/epi_studies.R, which reads the derived geometry and writes the small result files these charts read. Study 3 runs in your browser on the same rider model as the Rider page. The data and every assumption are described on the Data and methods page.
