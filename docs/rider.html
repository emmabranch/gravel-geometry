Put a rider on it

An estimated rider, drawn to scale on every size of a gravel bike, with joint angles and a check for sizes that look clearly too small or too large.

This is an estimate from average body proportions, not a bike fit. Real people’s legs, arms, and torsos vary a lot around the averages, and flexibility matters as much as length. Use it to narrow a shortlist, then get fitted.

import {riderOnBike, fitFlags, defaultCrank, defaultStem, DEFAULTS, INSEAM_RATIO} from "./js/rider.js"
import {bikeRiderMarkup, sharedViewBox} from "./js/draw.js"
import {fromUrl, shareButton} from "./js/share.js"
import {exportButtons, fileName} from "./js/export.js"

raw = FileAttachment("data/gravel_geometry_derived.csv").csv({typed: true})
bikes = raw.map(d => ({
  ...d,
  is_default_config: d.is_default_config === true || d.is_default_config === "TRUE",
  size_label: String(d.size_label),
  label: `${d.brand} ${d.model}`
}))
bikeList = Array.from(new Set(bikes.map(d => d.label))).sort((a, b) => a.localeCompare(b))

  {label: "Average Canadian man", height: 176, note: "mean of men aged 20 to 39 (177.7 cm) and 40 to 59 (174.7 cm)"},
  {label: "Shorter woman (5th percentile)", height: 153, note: "5th percentile, women aged 20 to 39 (153.3 cm)"},

1. The rider

  const wrap = html`<div class="preset-buttons" role="group" aria-label="Rider presets"></div>`;

    wrap.append(b);

viewof heightCm = {
  const input = Inputs.range([140, 205], {label: "Height (cm)", step: 1, value: fromUrl("h", 176, {min: 140, max: 205})});
  // a preset button sets the slider
  if (preset) { input.value = preset.height; }
  return input;
}
viewof useInseam = Inputs.toggle({label: "I know my inseam", value: fromUrl("useins", false, {bool: true})})
viewof inseamCm = useInseam
  ? Inputs.range([60, 100], {label: "Inseam (cm)", step: 0.5, value: fromUrl("in", Math.round(INSEAM_RATIO * heightCm * 2) / 2, {min: 60, max: 100})})
  : Inputs.range([60, 100], {label: "Inseam (cm), estimated", step: 0.5, value: Math.round(INSEAM_RATIO * heightCm * 2) / 2, disabled: true})

Inseam is the floor-to-crotch measurement, standing in socks with a book pressed up firmly. If you leave it off, it’s estimated as 47.5% of height.

Cockpit and setup

viewof stemMm = Inputs.range([50, 130], {label: "Stem length (mm)", step: 10, value: fromUrl("stem", defaultStem(heightCm * 10), {min: 50, max: 130})})
viewof stemAngle = Inputs.range([-17, 17], {label: "Stem angle (°)", step: 1, value: fromUrl("sa", DEFAULTS.stemAngle, {min: -17, max: 17})})
viewof spacersMm = Inputs.range([0, 50], {label: "Spacers under the stem (mm)", step: 5, value: fromUrl("sp", DEFAULTS.spacers, {min: 0, max: 50})})
viewof crankMm = Inputs.select([160, 165, 170, 172.5, 175], {label: "Crank length (mm)", value: fromUrl("crank", defaultCrank(heightCm * 10), {options: [160, 165, 170, 172.5, 175]})})

Starting values change with height: a 90 mm stem and 172.5 mm cranks suit a 176 cm rider, for example. Change them to match your own bike.

shareButton({

2. Every size of one bike

viewof gridBike = Inputs.select(bikeList, {label: "Bike", value: fromUrl("grid", "Norco Search C Gen 3", {options: bikeList})})
gridRows = bikes.filter(d => d.label === gridBike && d.is_default_config).sort((a, b) => a.size_order - b.size_order)
gridResults = gridRows.map(row => {
  const r = riderOnBike(row, riderIn, setup);
  return {row, r, fit: fitFlags(r)};
})
sizeGrid = {
  const vb = sharedViewBox(gridResults.map(d => ({row: d.row, rider: d.r})));
  const wrap = html`<div class="size-grid"></div>`;
  for (const d of gridResults) {
    const {markup} = bikeRiderMarkup(d.row, d.r, {colour: "#7a5c43"});
    const tile = html`<figure class="size-tile ${verdictClass(d.fit.verdict)}">
      <figcaption><strong>Size ${d.row.size_label}</strong><span class="verdict">${d.fit.verdict}</span></figcaption>
    </figure>`;
    tile.insertAdjacentHTML("beforeend", `<svg viewBox="${vb.vb}" role="img" aria-label="${heightCm} cm rider on ${gridBike} size ${d.row.size_label}: ${d.fit.verdict}">${d.markup ?? markup}</svg>`);
    const facts = html`<div class="tile-facts">Torso ${d.r.torsoAngle.toFixed(0)}° · knee ${d.r.kneeAngle.toFixed(0)}° · hoods ${d.r.hoodDrop >= 0 ? d.r.hoodDrop.toFixed(0) + " mm below" : (-d.r.hoodDrop).toFixed(0) + " mm above"} saddle</div>`;
    tile.append(facts);
    if (d.fit.reasons.length && d.fit.verdict !== "fits") tile.append(html`<div class="tile-why">${d.fit.reasons.join("; ")}</div>`);
    wrap.append(tile);
  }
  return wrap;
}

All sizes are drawn to the same scale. “Too small” and “too large” are rules of thumb, calibrated against manufacturers’ own size charts (see how the flags work).

How the rider is built

  • Body proportions. Thigh, shin, torso, upper arm, and forearm lengths are fixed fractions of height from Drillis and Contini (1966), the proportions most often used in biomechanics. For example, the thigh is 24.5% of height and the forearm 14.6%.
  • Inseam. If you don’t enter one, it’s 47.5% of height, from measured crotch height and stature in a NIOSH anthropometry survey.
  • Saddle height is 0.883 × inseam from the centre of the bottom bracket to the top of the saddle (the LeMond method), set along the seat tube’s angle.
  • Pedals. The knee angle is measured with the crank pointing straight down, the foot tilted about 13° toes-down, and the ball of the foot over the pedal axle.
  • Hands rest on the hoods, about 110 mm ahead of and 30 mm above where the bar clamps into the stem, with the elbows bent 15°.
  • Cockpit. The stem sits on 10 mm of headset cover plus the spacers you choose. Stem length starts at 70 to 100 mm depending on height. Cranks start at 165 to 175 mm.

How the flags work

Torso and shoulder angles turn out to change very little between sizes, because arms and torsos adapt. What changes is where the hands end up compared with the saddle. So the flags use:

  • Too small: hoods more than 3.8% of the rider’s height below the saddle (about 67 mm for a 176 cm rider).
  • Too large: hoods more than 5.5% of height above the saddle, saddle to hoods more than 51% of height, less than 7% of height of seatpost showing, or published standover more than 20 mm above inseam plus shoes.
  • On the small side or on the large side: the hoods are close to those limits.

These limits were chosen by comparing the model with the rider height ranges that Trek, Canyon, Devinci, Salsa, Lauf, and BMC publish for 48 sizes of 9 bikes. Checked by leaving each bike out in turn, the rules flagged 7% of sizes the manufacturer recommends for that height, caught 86% of sizes at least 6 cm too small and 82% at least 6 cm too large, and never flagged in the wrong direction.

They are rules of thumb. A size flagged “fits” can still be wrong for you, and one flagged “on the large side” can be right with a shorter stem.
